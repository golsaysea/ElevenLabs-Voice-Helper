# ElevenLabs Voice Helper (ElevenLabs 辅助语音生成插件)

Chrome Manifest V3 扩展程序：支持 ElevenLabs 批量语音合成 (TTS)、**最新官方音频效果 (`🎛️ 音频效果`：空格混响 `Small Room` / `Big Room` / `Hall` + `+ 添加效果` 滤波器与背景环境音)**、**自动检查 GitHub 更新提示与一键下载更新包 (`🔄`)**、多 API 负载均衡与自动故障切换、首句试听缓存 (`🔊 试听首句`)、标点短句智能时长估算、超 3 分钟文案顶部红色提示与手动拆分为 2 段 (`🔴 超3分钟·可拆分`)、一键复制到谷歌表格/Excel (`📋 复制到表格`)、批量导出自动备份 `000_文案对照表.csv`、重名/误复制声音一键清理 (`🧹 清理声音`)，以及 AI 音效 / 免费 BGM 配乐降级生成 / 变声 / 人声提取 / 语音转文字工坊 (`🧰 其他工具`)。

## 包含版本 (Packages)

- `packages/elevenlabs-token-helper` — **网页 Token 自动识别捕获版** (`v3.4.0`)
- `packages/elevenlabs-api-helper` — **API 密钥批量辅助版** (`v6.7.0`)

## 核心功能亮点 (Key Features)

1. **🎛️ 最新 ElevenLabs 音频效果 (`音频效果` / `audio_effects`)**
   - 1:1 还原 ElevenLabs 网页最新 **音频效果** 面板：支持 **🏠 空格 (空间混响)**（`Small Room`、`Big Room`、`Hall`、`Tunnel`、`Street`、`Valley`、`Forest`）与右侧 `⊖` 一键清除按钮，点击 **`+ 添加效果`** 可展开更多效果（**📻 滤波预设** `Phone` / `Old Radio` / `Cheap Microphone` / `Robot`、**🌧️ 背景环境音** `Cafe` / `Office` / `Call Center` / `City` / `Keyboard`、**混响量 `send_level`** 与 **声源距离 `distance`**），并支持一键同步官方 `/v1/audio-effects/catalog` 目录及单声道/不支持接口自动回退。
2. **🔄 自动检查 GitHub 更新提示 & 一键下载更新包**
   - 插件底部默认开启 **`🔄 自动检查 GitHub 更新提示`**，顶部配备 `🔄` 手动检查按钮；当 GitHub 发布新版本时，顶部自动弹出绿色更新提示条，支持点击 **`⬇️ 一键下载更新包`** 直接将最新 `.zip` 下载到 `下载/ElevenLabs_Pro/插件更新包/` 目录。
3. **🔊 首句极速试听 (`试听首句`)**
   - 自动提取每段文案的第一句话合成试听（同步应用当前所选音频效果），内置内存缓存避免重复扣费，试听不触发下载或自动删除。
4. **🔴 智能时长估算与超 3 分钟手动拆分为 2 段 (`🔴 超3分钟·可拆分`)**
   - 综合中英文词数、数字、标点停顿及短句密度精准估算语音时长；超过 3 分钟（>180 秒）的段落**默认不自动拆分**，而是在顶部工具栏显示醒目红色按钮 `🔴 超3分钟·可拆分 (N段)` 及单卡 `✂️ 超3分·可拆分`，仅在用户主动点击时按段落/句末/转折词边界均分为 2 段。
5. **📋 一键复制到表格 & 自动保存 `000_文案对照表.csv`**
   - 点击顶部 `📋 复制到表格` 即可将当前全部文案（或刚生成完被自动清理的批次文案）按每段一行复制到剪贴板，直接 `Ctrl+V` 粘贴回 Google Sheets / Excel；每次批量生成下载完成时，还会在音频同一输出文件夹下自动生成带 UTF-8 BOM 的 `000_文案对照表.csv` 备份。
6. **🧹 声音清理与重名去重管理 (`🧹 清理声音`)**
   - 自动检测同名重复声音，默认保留每组第 1 个并勾选多余副本；支持搜索、预览试听、一键从云端删除多余声音（释放声音槽位）或本地屏蔽隐藏，并在主界面下拉框自动合并同名声音。
7. **🧰 多合一 AI 音频工坊 (`🧰 其他工具`)**
   - 支持 **AI 音效生成** (`/v1/sound-generation`)、**AI 音乐生成**（默认免费 BGM 配乐降级模式，手动指定付费账号与模型时调用 `/v1/music` 并自动兼容回退 `music_v1`）、**语音变声** (`/v1/speech-to-speech`)、**人声提取降噪** (`/v1/audio-isolation`) 与 **语音转文字** (`/v1/speech-to-text`)。
   - 默认优先调度仅含系统声音且剩余额度充足的 API Key，自动保护自定义克隆声音专属额度。

## 安装与在线更新方式 (Installation & Update)

1. 从本仓库 [Releases](https://github.com/golsaysea/ElevenLabs-Voice-Helper/releases) 下载对应版本的 `.zip` 压缩包（或直接点击插件内顶部的 **`⬇️ 一键下载更新包`**）并解压到本地文件夹。
2. 打开 Chrome / Edge 浏览器扩展管理页面 `chrome://extensions/`，开启右上角 **开发者模式 (Developer mode)**。
3. 点击左上角 **加载已解压的扩展程序 (Load unpacked)**，选择解压后的文件夹即可使用（更新时解压覆盖原目录并在 `chrome://extensions/` 点击刷新即可）。
